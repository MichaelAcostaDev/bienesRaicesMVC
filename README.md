🏡 Bienes Raíces MVC

A real estate management web application built with **PHP using the MVC (Model-View-Controller) architecture**.

The application allows users to browse real estate properties, view property details, and manage property listings through an administrator system.

✅ **Features**

- 🔐 User authentication
- 👤 User management
- 🏠 Property management
- 📝 Property listing creation and management
- 💰 Property pricing
- 🛏️ Property information and features
- 📞 Seller information
- 🖼️ Property images
- 🗄️ MySQL/MariaDB database integration
- 🔒 Password hashing
- 📱 Responsive frontend

👾 **Technologies**

- PHP
- MVC
- MySQL / MariaDB
- HTML5
- CSS3
- JavaScript
- Sass
- Gulp
- NPM
- Composer
